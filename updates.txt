Toolbox Update 3.3
🧩 Smart Context - Cards
- AI Card Management lets the AI select which prompt cards are in context after each output by creating Load and Unload statements in its outputs.
- Only Prompt story cards of specific types are managed by the AI
- Managed types: World, Region, Location, Faction, Species, Character, Event, Lore, Quest, Item, Recipe
- There is a one-turn delay to information visibility. If the AI requests a card, it will only see that card on its next output, after that request has been processed.

🧩 Smart Context - Summaries
- Improved Story Summarization creates summary cards from the oldest parts of the story when they overflow context.
- Portions of the story that have been summarized are hidden from the AI and replaced with their summaries in order to save space in context.
- Summaries use a full output from your current AI model, and only happen on "continue" actions when you are over your context limit.
- Improved Story Summarization works best for context sizes of 6000+, and should NOT be used alongside AI Dungeon's native Auto Summarization feature. 

Bug Fixes
- Fixed issue where Direct text was sometimes hidden from the AI before its fade distance.
- Fixed Reflect and Motive creating duplicates on retry
- Fixed Reflect and Motive blurbs not properly updating when edited
- Fixed reflections fading immediately, rather than at their configured distance

Toolbox Update 3.2
⚡ Speed Tool
- /speed tool added, which lets you set the narration speed to 0.1x, 0.25x, 0.5x, 1x, 2x, 4x, or 10x, e.g., /speed 4
- Using the command without a numerical request cycles through speeds
- Using the command once creates persistent instructions (even at 1x speed). These can be removed with /speed reset

Bug Fixes
- Cleaned up how Motive and Reflect select characters / cards to modify
- Various minor bug fixes


Toolbox Update 3.1

Response Length Placeholder
- You can now set your default Tool Output Size and CYOA Choice Size at the start of an adventure by using a placeholder
- The placeholder must start with "Response Length", e.g., ${Response Length: Enter your Response Length (100-400)}
- The value entered must be a number. Leaving it blank or entering anything else defaults to 200
- Tool Output Size is set to 75% of Response Length, and CYOA Choice Size is set to 12.5% of Response Length

Bug Fixes
- Fixed various typos
- Fixed issue with certain placeholder cards not being removed
- Fixed issue where prompt cards and story cards created from prompts had the wrong descriptions

Toolbox Update 3.01

Card
- Enabled compound requests for Cards. Now the text before the semicolon on a request is the desired card name or topic, and the text after a semicolon is the instructions, e.g., "/card Kevin; a mechanic at FixQuick"
- Enabled a prompt toggle option for Cards. You can include "-p" after the slash command and before the request to switch Card outputs between prompt and story cards. This option reverses the default, so if it defaults to prompt cards it will get switched to a story card, e.g., "/card -p Kevin"
- Fixed a bug where undoing a card command and immediately re-using the command would overwrite the first card
- Fixed a bug where Prompt cards were getting triggers when they shouldn't

Motive and Reflect
- Fixed a bug where motives and reflections for characters without cards weren't properly creating Mind cards.
- Now, as intended, if you want to use Motive or Reflect for a character that doesn't have a card, you can, and it will create a new card to house that character's motives and reflections. The card will have the name "🧠 ${character name} - Mind" and the type "Prompt - Mind"

Toolbox Requirements
- Removed the Raw Model Output requirement listed in Toolbox's Help command.
- Raw Model Output is required for Universal Generator, but not Toolbox itself.
